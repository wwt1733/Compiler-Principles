# ===========================================================================
# TINY 语言的全部单词（正则表达式规格文件）
# ---------------------------------------------------------------------------
# 命名规则：
#   名字_编码      -- 该正则式需要生成 DFA 图；下划线后的数字即该单词的编码
#   名字_编码L     -- 该命名对应多个单词，编码从该数值起连续分配（L = Launch）
#   Comment_编码   -- 注释：参与自动机构造，但词法分析时不输出单词编码
#   Keyword编码L   -- 关键字：不构造自动机（与 ID 正则重复），只登记编码
#   名字=          -- 不带编码者视为宏定义，只在正则式中做文本替换
# 约定：空串用 # 表示；+ * 等运算符号作字面量时须写成 \+ \*
# ===========================================================================

digit=[0-9]
letter=[a-zA-Z]

Keyword103L=if | then | else | end | repeat | until | read | write
Comment_102=\{ (~ \})* \}
Num_100=digit+
ID_101=letter(letter|digit)*
Symbol200L= \+ | - | \* | / | % | ^ | < | <= | <> | > | >= | = | \{ | \} | ; | := | \( | \)
